# Rabbit AR Server (Android) 설치와 운영

대상: Samsung Galaxy S26 Ultra (arm64, Snapdragon 8 Elite Gen 5). GenieX SDK 의 요구사항은 minSdk 27, arm64-v8a 다.

> 이 앱은 실기기에서 한 번도 실행해 보지 못했다. 아래 절차는 코드가 의도한 동작이며,
> 실제 확인 항목은 [DEVICE_VERIFICATION.md](DEVICE_VERIFICATION.md) 에 있다.

## 빌드와 설치

```bash
cd apps/rabbit-server-android && ./gradlew assembleDebug
```

결과: `app/build/outputs/apk/debug/app-debug.apk` (약 107 MB — GenieX 네이티브 라이브러리 포함).

USB 디버깅을 켠 폰에:

```bash
adb install -r apps/rabbit-server-android/app/build/outputs/apk/debug/app-debug.apk
```

debug 서명 빌드다. 배포용 서명 APK 는 만들지 않았다(개인 기기에 직접 설치하는 용도).

## 최초 설정 (한 번만)

앱을 처음 열면 설정 화면이 나온다.

1. **릴레이 주소** — `https://rabbit-ar-relay.<계정 서브도메인>.workers.dev` (SETUP_WORKERS.md 에서 배포한 주소)
2. **단말 토큰** — `wrangler secret put DEVICE_TOKEN` 에 넣은 것과 같은 값. Android Keystore 로 암호화해 저장하고 다시 보여 주지 않는다.
3. **추론 엔진**
   - *GenieX 온디바이스*: 모델 이름·양자화·연산 장치·런타임을 고른다.
     기본값은 GenieX 공식 빠른 시작의 예시 모델(`unsloth/Qwen3-0.6B-GGUF`, `Q4_0`)이다.
     이것은 "동작 확인용" 기본값일 뿐이다. 전시에 쓸 모델은 실기기에서 한국어 품질과 속도를 보고 고른다.
     Qualcomm AI Hub 모델(`ai-hub-models/…`)은 칩셋(`SM8850`)을 적어야 하고 NPU 전용이다.
   - *MOCK*: 모델 없이 미리 준비한 답변을 흘려보낸다. 릴레이·웹 연결을 먼저 시험할 때 쓴다. 관람객 화면에 MOCK 이라고 표시된다.
4. **저장**.

모델 가중치는 첫 "서버 시작" 때 한 번 내려받는다(Wi-Fi 권장, 이어받기 지원). 모델의 라이선스는 받기 전에 확인한다.

## 평소 사용: 버튼 하나

**서버 시작** 을 누르면 순서대로 진행한다.

```
중지됨 → 모델 로딩 중 → 연결 중 → 온라인
```

- *모델 로딩 중*: GenieX 초기화 → (필요하면 내려받기) → 메모리에 올리기
- *연결 중*: 릴레이에 WebSocket 연결, 토큰 인증
- *온라인*: 릴레이가 `hello` 를 받아 준 시점. 이때부터 관람객 질문이 들어온다

**서버 중지** 를 누르면: 새 질문 차단 → 진행 중인 질문 정리 → 연결 종료 → 모델 해제.
릴레이는 연결이 끊긴 즉시 관람객에게 `offline` 을 알리고, 웹은 사전제작 답변으로 넘어간다.

알림창의 "Rabbit AR Server 실행 중" 알림에서도 중지할 수 있다.

## 화면에서 볼 수 있는 것

- 현재 단계와 이유, 최근 오류
- 대기 중인 질문 수, 동시 대화 수, 답한 수/실패 수, 응답 시간(중앙값·최근), 온라인 유지 시간
- **모델·연산 장치 진단**: 엔진(GenieX / MOCK), SDK 버전, 모델 파일 경로, 런타임, 요청한 연산 장치, 로딩 시간, 최근 생성 속도(토큰/초), 첫 토큰까지 걸린 시간
- 앱 메모리, 발열 상태, 기기·칩셋 이름
- 최근 기록 (상태 변화만. **질문·답변 내용은 화면에도 저장소에도 남기지 않는다**)

## 오류가 났을 때

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 단말 토큰이 … 달라요 (401) | 토큰 불일치 | 최초 설정에서 토큰 다시 입력 |
| 릴레이에 DEVICE_TOKEN 이 설정되지 않았어요 (503) | Worker secret 누락 | `wrangler secret put DEVICE_TOKEN` |
| 다른 기기가 같은 토큰으로 접속했어요 | 두 번째 단말이 붙음 | 다른 기기의 서버를 끄고 다시 시작 |
| 모델 내려받기 실패 | 네트워크·모델 이름·권한 | 이름·양자화 확인, Wi-Fi 확인 |
| 모델 로딩 실패 | 메모리 부족, 지원하지 않는 조합 | 연산 장치를 GPU/CPU 로 바꾸거나 더 작은 모델 |
| 다시 연결 중 | 네트워크 끊김 | 자동으로 다시 붙는다 (최대 30초 간격) |

NPU 로 안 되면 GPU → CPU 순으로 바꿔 본다. 무엇으로 돌고 있는지는 진단 패널에 그대로 나온다.

## 이 앱이 하지 않는 것

- 포트를 열지 않는다. 밖으로 나가는 WebSocket 하나만 쓴다.
- 문자·연락처·파일·다른 앱·OS 명령에 접근하지 않는다. 그런 코드를 호출하는 경로가 없다.
- 관람객 대화를 저장하지 않는다. 세션 문맥(직전 문답 한 쌍)은 메모리에 10분만 둔다.
- 시스템이 서비스를 죽였을 때 스스로 되살아나지 않는다(소유자가 모르는 사이 공개 서버가 켜지지 않도록).
- 포그라운드 서비스라고 해서 Android 가 끝까지 살려 둔다고 보장하지 않는다. 전시 중에는 충전기를 꽂고 배터리 최적화를 끈다.
