# 보안과 공개 범위

이 시스템은 "학술 전시에서 포스터에 대한 질문에 답하는 것" 하나만 한다.
개인 비서, 메시지·메일, 파일, 기기 제어를 외부에 연결하는 것은 목표가 아니며 그런 경로를 만들지 않았다.

## 비밀값

| 값 | 어디에 있나 | 어디에 없어야 하나 |
|---|---|---|
| `DEVICE_TOKEN` | Cloudflare Worker secret, 폰의 Android Keystore(암호화) | 저장소, 웹 코드, 문서, 로그, 알림, QR |
| 릴레이 주소 | 웹 빌드(`VITE_RELAY_URL`), 앱 설정 | (공개 정보라 숨길 필요 없음) |
| 모델 가중치 | 폰 저장소 | 저장소 (`.gitignore` 가 `*.gguf` 등을 뺀다) |

웹(JavaScript)에는 비밀을 넣을 수 없으므로 넣지 않았다. 관람객 쪽 접근은 익명이고, 남용은 아래 제한으로 막는다.

로컬 개발용 `.dev.vars` 는 git 에 올라가지 않는다. `.dev.vars.example` 의 값은 로컬 전용 예시다.

## 공개 엔드포인트의 남용 방지

- 스키마 검증: 허용한 필드·형식·길이가 아니면 거부하고 연결을 끊는다.
- 속도 제한: 세션당 분당 6, IP 당 분당 20, 하루 3,000, 세션당 동시 1, 대기열 8.
- `requestId` 재사용 거부.
- 출처 제한(`ALLOWED_ORIGINS`): 브라우저에서 오는 요청을 거른다. 스크립트로 직접 치는 요청은 못 막으므로 인증으로 보지 않는다.
- 응답 길이 제한: 답변 900자, 스트림 총량 상한.
- 필요하면 Cloudflare Turnstile 을 `/v1/chat` 앞에 붙일 수 있다(구현하지 않음). 전시 규모에서 위 제한으로 부족할 때 고려한다.

## 폰을 지키는 것

- 폰은 포트를 열지 않는다. 릴레이로 나가는 연결 하나뿐이다.
- 단말 연결은 토큰이 맞아야 열린다. 토큰은 해시로 상수 시간 비교한다. 24자 미만 토큰은 거부한다.
- 릴레이가 넘겨 준 질문도 앱에서 다시 검증한다(형식, 길이, 주제 ID).
- LLM 에 넘기는 것은 고정 시스템 규칙 + 고른 연구 사실 + 질문 글자뿐이다. 도구 호출·파일·네트워크 기능을 모델에 주지 않는다.
- 모델 출력에서 쓰는 것은 글자와 동작 ID 하나뿐이고, 동작 ID 는 앱·릴레이·웹 세 곳에서 각각 허용 목록으로 거른다.
  웹은 답변을 `textContent` 로만 넣는다. `eval`, 동적 스크립트, 임의 URL 호출이 없다.
- 프롬프트 주입("규칙을 무시해" 등)이 통해도 일어날 수 있는 일은 "이상한 글자 답변"까지다. 실행할 수 있는 것이 없다.
  다만 **모델이 틀린 과학 설명을 할 가능성은 남아 있다.** 짧고 뚜렷한 질문은 검증된 사전제작 답변으로 먼저 처리해 이 위험을 줄였다.

## 개인정보

- 관람객: 계정·이름·연락처를 받지 않는다. 세션 ID 는 탭마다 새로 만드는 임시 값이다.
- 카메라 영상은 관람객 기기 안에서만 처리된다. 서버로 보내지 않는다.
- 대화 내용은 릴레이에도 폰에도 저장하지 않는다. 폰은 직전 문답 한 쌍을 메모리에 10분 두었다가 지운다.
  릴레이가 저장하는 것은 날짜별 처리 건수뿐이다.
- 소유자 화면(대시보드)에도 질문·답변 내용은 나오지 않는다.

## 공개 저장소에 올라가는 것

| 올라감 | 올라가지 않음 (기본) |
|---|---|
| 소스 코드, 문서 | `reference/` (인쇄 원본 PDF/PNG, 실험 슬라이드) |
| `poster_facts.json` 등 교육 콘텐츠 (포스터에 이미 실린 수치) | `_handoff/` (인계 패키지 원본) |
| `poster.mind` (포스터 특징점 데이터 — AR 에 필수) | 모델 가중치, 토큰, `.dev.vars`, 서명 키 |
| 토끼 설정화 시트 | |

`reference/source_experiments/` 의 실험 슬라이드는 이 프로젝트에서 열어 보지도, 콘텐츠에 쓰지도 않았다.
원본 PDF 를 공개하고 싶으면 `.gitignore` 에서 해당 줄을 빼면 된다. 그 결정은 소유자가 한다.

포스터의 별표(*) 표기가 교신저자를 뜻하는지는 확인되지 않았으므로, 새 포스터에서는 별표를 빼고 이름만 적었고
이메일 같은 연락처를 만들어 넣지 않았다.
