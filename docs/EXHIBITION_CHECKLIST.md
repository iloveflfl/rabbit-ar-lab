# 전시 체크리스트

## 전날까지

- [ ] 붙일 A1 인쇄물이 `reference/CURT_…_Poster.pdf` 와 같은 판인지 확인 (제목의 `Temperature-Depending` 은 인쇄 원본 그대로 둔다. AR 화면의 새 제목만 `Temperature-Dependent`)
- [ ] 인쇄물로 인식 시험 완료 (DEVICE_VERIFICATION.md C 항목), 필요한 보정 반영
- [ ] 릴레이 배포, GitHub Pages 배포, 두 주소 확정
- [ ] QR 스티커 인쇄 (한 변 45~50 mm, 흰 여백 포함) — **주소가 확정된 뒤에만**
- [ ] 폰에 앱 설치, 최초 설정, 모델 내려받기 완료 (전시장 Wi-Fi 에 기대지 않도록 미리)
- [ ] 폰: 앱 정보 → 배터리 → '제한 없음', 알림 허용
- [ ] 폰으로 MOCK 이 아닌 실제 엔진에서 표준 질문 3개 답변 확인
- [ ] 관람객용 폰(다른 기기)으로 QR → AR → 질문까지 한 번 끝까지

## 설치

- [ ] 포스터를 평평하게, 눈높이에. 구겨지거나 휘면 인식이 나빠진다
- [ ] 조명이 포스터에 직접 반사되지 않는 위치 (유광 인쇄면 특히)
- [ ] 포스터 앞 1~1.5 m 공간 확보
- [ ] QR 스티커: CONCLUSIONS 띠 오른쪽 빈 곳에 부착
- [ ] 부착 뒤 인식 재확인 (정면, 좌우 30°)
- [ ] 폰은 충전기에 연결, 통풍되는 곳에 (케이스를 벗기면 발열에 유리)
- [ ] 폰 네트워크: 전시장 Wi-Fi 가 불안하면 LTE/5G 로

## 시작

- [ ] 앱에서 **서버 시작** → `온라인` 확인
- [ ] 진단 패널에서 엔진이 `GenieX 온디바이스` 인지, 연산 장치·생성 속도가 예상대로인지
- [ ] 다른 폰으로 QR → 랜딩에 "토끼 채팅 서버 온라인"
- [ ] 질문 하나 보내서 답과 토끼 동작 확인

## 운영 중

- [ ] 1시간마다: 앱이 `온라인` 인지, 발열 상태가 '따뜻함' 이하인지
- [ ] '뜨거움' 이상이면 서버를 잠시 중지하고 식힌다 (웹은 사전제작 답변으로 계속 동작한다)
- [ ] 관람객이 "안 잡혀요" 라고 하면: 조금 뒤로, 포스터 전체가 화면에, 반사 없는 각도로. 그래도 안 되면 "AR 없이 2D로 보기"

## 문제가 생기면

| 증상 | 조치 |
|---|---|
| 앱이 `다시 연결 중` | 네트워크 확인. 자동으로 다시 붙는다 |
| 앱이 `오류` | 표시된 이유 확인 → 서버 시작 다시 |
| 앱이 꺼져 있음 (시스템이 종료) | 서버 시작 다시. 배터리 최적화 설정 재확인 |
| 답이 너무 느림 | 더 작은 모델, 또는 MOCK 대신 웹의 사전제작 답변에 맡기고 서버 중지 |
| 웹이 "오프라인" 이라고 나옴 | 폰 앱 상태 확인. 관람객은 사전제작 답변으로 계속 체험 가능 |
| 질문이 몰림 | 릴레이가 대기열(8)과 속도 제한으로 막는다. 넘치면 사전제작 답변이 나간다 |
| AR 이 아예 안 됨 (카메라·브라우저 문제) | 2D 보기 안내 |

서버가 완전히 죽어도 관람객 쪽은 포스터 내용과 사전제작 Q&A 를 전부 볼 수 있다.
